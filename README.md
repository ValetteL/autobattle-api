Backend multijoueur en PHP (Symfony), avec WebSockets pour les combats temps réel, gestion d’inventaire, boutique et authentification sécurisée.

# Autobattle API

🔧 **Stack** : PHP (Symfony), WebSockets, MySQL  
🎮 **Objectif** : Fournir une API backend pour un jeu de combat multijoueur avec gestion de personnages, équipements, boutique, et combats temps réel.

## 🧠 Fonctionnalités

- Authentification sécurisée (sessions ou JWT)
- Gestion de l’inventaire et du shop
- Système de combat temps réel via WebSockets
- API REST pour les opérations classiques

## 📦 Stack technique

- PHP 8.1 / Symfony
- WebSocket server (Ratchet / Wamp)
- Base de données MySQL
